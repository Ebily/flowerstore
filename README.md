# FLORA — واجهة متجر زهور كاملة للتجربة

هذه نسخة **frontend only** مستقلة عن FastAPI وSQLite، ويمكن دمجها مع المشروع السابق لاحقًا. تحتوي على:

- الصفحة الرئيسية ذات وردة متحركة بطبقات CSS ثلاثية الأبعاد، ولمسة كلاسيكية، وتصميم للهاتف والكمبيوتر.
- متجر باقات مع البحث والتصنيف والترتيب، وصفحة تفاصيل لكل منتج.
- اقتراحات حسب المناسبة واللون والميزانية، قابلة لاحقًا للربط بمحرك التوصيات.
- تخصيص باقة بحسب الورد واللون والعدد والتغليف ورسالة الإهداء، مع سعر ومعاينة تقديريين.
- سلة قابلة للتعديل، نموذج إتمام طلب، صفحة تأكيد، وسجل طلبات.
- تبديل عربي/إنجليزي مع اتجاه RTL/LTR، وتذكّر اللغة في المتصفح.

**الطلبات تجريبية فقط** وتُحفظ محليًا في هذا المتصفح باستخدام `localStorage`. لا تُرسل إلى متجر ولا تجري عملية دفع أو توصيل. لا تُدخلي بيانات شخصية حقيقية أثناء التجربة. تكلفة التوصيل المعروضة مبلغ تجريبي.

## التشغيل على Mac داخل VS Code

افتحي مجلد `FLORA_Frontend_Motion` في VS Code وشغّلي:

```bash
python3 -m http.server 3000
```

افتحي <http://localhost:3000>. زر **الزهور** يقود للمتجر، و**اقتراحات لك** للمساعد، و**صمّمي باقتك** للتخصيص، والسلة تقود لإتمام الطلب. لا تحتاج هذه الواجهة تثبيت مكتبات. الخطوط الخارجية اختيارية.

## الربط بالخلفية لاحقًا

`catalog.js` مصدر المنتجات التجريبية الثمانية ومعرّفاتها متطابقة مع قاعدة FLORA الأولية. استبدليه ببيانات `GET /products`، ثم اربطي السلة والطلبات والتوصيات بمسارات `/cart` و`/orders` و`/recommendations`. واجهة تخصيص الباقة تحتاج حفظ خيارات الباقة وسعرها في الخلفية عند الدمج. أحداث إضافة المنتج من الرئيسية تحمل اسم `flora:preview-add-to-bag`.
